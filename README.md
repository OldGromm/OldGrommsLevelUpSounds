**OldGromm's Level-Up Sounds** is an add-on for *World of Warcraft* that plays your music files after leveling up.

# Installation
Place the folder inside "World of Warcraft\_retail_\Interface\AddOns".

Other versions of the game have different folder names like "_classic" or "_forever_".

If the "AddOns" folder doesn't exist already, create it first.

# Setup
Place your audio files inside the "files" folder. This has to be done before you start the game.

The files have to be renamed to be just numbers. Double-digit with a leading zero (01, 02 etc).

Furthermore, the files have to be converted to the .ogg format.
